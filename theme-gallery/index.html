路线 A · 换皮

保留现有构建，只借用主题的视觉语言

  • 保留 build.py、JSON 数据、JS 渲染器，以及论文库筛选、跨页链接、check_* 检查这些现有功能
  • 只改 styles.css 和 shell.html，不引入新依赖，大约一次会话就能完成

  • 代价是 11 个 JS 页面渲染器要改写成模板或组件，论文库、方向评审这些数据页要写自定义组件，检查脚本也要重写

我的初步建议

  1. 想最快见效：走路线 A，用 #5 Lil'Log / PaperMod 的阅读版式处理正文（窄栏、大字号、克制配色），再加上 #1 Distill 或 #3 Tufte 的旁注和引用悬停卡片。数据页照样用现有渲染器。
  2. 想长期维护、以后持续写：走路线 B，迁到 #4 Quarto。它是为科研写作设计的：BibTeX 引用、页边旁注、交叉引用、搜索、深浅色、多页侧栏都是自带的，同一份源文件还能导出 PDF。
  3. 想要知识库或文档站的观感：看 #12 Hextra（Hugo，不需要 Node，自带 KaTeX）、#10 Starlight 或 #9 Zensical。
